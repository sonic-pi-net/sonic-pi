# QR Code generator library (C++)

Project Nayuki's, v1.8.0, unmodified: `cpp/qrcodegen.hpp` and `cpp/qrcodegen.cpp` from
https://github.com/nayuki/QR-Code-generator/tree/v1.8.0. MIT License (in each file's header).

The share link's codec (`../sharelink_qr.cpp`) draws a link as a QR code with it, for native Sonic Pi and, compiled
to wasm, for the web's page: both show the same code for the same link.
